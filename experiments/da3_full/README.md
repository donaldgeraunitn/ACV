# Single-image Gaussian reconstruction with Depth Anything 3

DA3METRIC-LARGE predicts the first metric depth map and provides four transformer feature maps. A small convolutional head uses RGB, the first depth map and early DA3 features to predict a signed log-depth offset per pixel. The second depth is `z2 = z1 * exp(offset)`. The offset starts at zero during training. SHARP initializes Gaussians from these two depths and refines them using adapted DA3 features.

The two checkpoints share this architecture. In both, the feature adapter and second-depth head were trained. The tuned checkpoint also updates the final fusion block, geometry and texture branches, and Gaussian prediction head. It is the default for inference.

## Installation and weights

Run the commands from the repository root in a Python 3.12 environment with a compatible PyTorch installation. Training and Middlebury rendering use a CUDA GPU and gsplat.

```bash
python -m pip install -e .
python -m pip install "depth-anything-3 @ git+https://github.com/ByteDance-Seed/Depth-Anything-3.git@3d835ec1a5802d64a8b8b15f817a1ab54809bfe4"
python -m pip install lpips==0.1.4 DISTS-pytorch==0.1
hf download depth-anything/DA3METRIC-LARGE config.json model.safetensors --revision 4010e39f3634a45bc60553321fb49fb760bd594e --local-dir models/DA3METRIC-LARGE
curl -fL --create-dirs -o models/sharp_2572gikvuh.pt https://ml-site.cdn-apple.com/models/sharp/sharp_2572gikvuh.pt
```

Only the Gaussian decoder and prediction head are initialized from the official SHARP weights. Depth Pro is never executed by this experiment. The branch includes the learned adapter and second-depth weights, plus the fine-tuned decoder blocks for the tuned variant. [DA3 model card](https://huggingface.co/depth-anything/DA3METRIC-LARGE)

## Reconstruct one photograph

```bash
python experiments/da3_full/predict.py --input photo.jpg --output scene.ply --da3-checkpoint models/DA3METRIC-LARGE --sharp-checkpoint models/sharp_2572gikvuh.pt
```

Use `--focal-px` when the focal length in pixels is known. The default uses the SHARP EXIF estimate. To use the frozen-decoder variant, add `--checkpoint experiments/da3_full/checkpoints/learned-frozen.pt`. Both produce metric Gaussians in the source-camera coordinate system.

## Reproduce training

The synthetic RGB-D stage uses 80 training scenes and 16 validation scenes. Stage two uses 68 WildRGB-D training sequences, 17 each from cellphone, bucket, apple and car. Each sequence supplies four pseudo-pairs generated by the selected synthetic-stage checkpoint. Both variants start from this checkpoint and receive the same 272 pseudo-pairs in the same order for 288 updates. The validation set contains six separate cellphone sequences. The reference runs used seed 617, batch size one and a 768 × 768 training grid.

The training script reads the official category ZIPs from the archive directory when available. Otherwise it downloads and caches the required ZIP members. It saves the two final training checkpoints under `runs/da3/frozen/last.pt` and `runs/da3/tuned/last.pt`. The bundled inference checkpoints contain the learned tensors from update 288. Retraining results can vary with the CUDA and PyTorch configuration. [WildRGB-D data](https://github.com/wildrgbd/wildrgbd)

```bash
curl -fL --create-dirs -o models/vgg16-397923af.pth https://download.pytorch.org/models/vgg16-397923af.pth
python experiments/da3_full/run_training.py --output runs/da3 --archives datasets/wildrgbd --da3-checkpoint models/DA3METRIC-LARGE --sharp-checkpoint models/sharp_2572gikvuh.pt --vgg-weights models/vgg16-397923af.pth
```

## Evaluate on Middlebury 2014

Use the 23 publicly labelled scenes with perfect calibration. Each `datasets/middlebury/SCENE-perfect/` directory should contain `im0.png`, `im1.png` and `calib.txt`. The predictor takes the left photograph and the renderer uses the calibrated right camera. LPIPS-Alex v0.1 and DISTS compare the rendering with the full-resolution right photograph. [Official Middlebury data](https://vision.middlebury.edu/stereo/data/scenes2014/)

```bash
python experiments/da3_full/evaluate.py render --dataset datasets/middlebury --output runs/middlebury --da3-checkpoint models/DA3METRIC-LARGE --sharp-checkpoint models/sharp_2572gikvuh.pt
python experiments/da3_full/evaluate.py score --dataset datasets/middlebury --output runs/middlebury
```
